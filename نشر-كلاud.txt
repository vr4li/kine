# نشر دأب على daab (مرة واحدة — بدون رفع يدوي)

## 0) الرابط الرسمي

**https://daab-web.pages.dev** (مشروع Pages: **daab-web**).  
`daab.pages.dev` محجوز عند Cloudflare. المشروع القديم `kine-enf.pages.dev` عُطّل نشره التلقائي.

## 1) GitHub مربوط بمشروع daab-web

Workers & Pages → **daab-web** → **Settings** → **Builds**  
→ **Connect to Git** (أو Create deployment → Git)

- Repository: **vr4li/kine**
- Branch: **main**
- Framework: **None**
- Build command: *(فاضي)*
- **Build output directory:** `public`  ← مهم جداً
- **Root directory (advanced):** *(فاضي)*

Save → **Retry deployment** أو **Deploy**

## 2) بعدها

كل ما تعدّلين الموقع على GitHub، Cloudflare ينشر تلقائياً.  
الرابط الرسمي: **https://daab-web.pages.dev** (النشر التلقائي من Git يبقى على مشروع **daab** حتى توصّلين **daab-web** بنفس الريبو من لوحة Cloudflare)

## 3) تحديث التصميم من الماك

```bash
cd ~/Desktop/aidab
# عدّلي index.html ثم:
cp index.html public/index.html
git add index.html public/index.html
git commit -m "update site"
git push
```
