# نشر دأب على daab (مرة واحدة — بدون رفع يدوي)

## 0) إعادة تسمية المشروع من kine إلى daab (مرة واحدة)

Workers & Pages → **kine** → **Settings** → **Rename project** → اكتبي **daab** → Save.

بعدها يصبح الرابط الافتراضي مثل **https://daab.pages.dev** (أو **daab-XXXX.pages.dev** حسب حسابك).

## 1) اربطي GitHub بمشروع daab

Workers & Pages → **daab** → **Settings** → **Builds**  
→ **Connect to Git** (أو Create deployment → Git)

- Repository: **vr4li/kine**
- Branch: **main**
- Framework: **None**
- Build command: *(فاضي)*
- **Build output directory:** `public`  ← مهم جداً
- **Root directory (advanced):** *(فاضي)*

Save → **Retry deployment** أو **Deploy**

## 2) بعدها

كل ما تعدّلين الموقع على GitHub، Cloudflare ينشر تلقائياً.  
الرابط: **https://daab.pages.dev** (أو الرابط الافتراضي للمشروع بعد إعادة التسمية)

## 3) تحديث التصميم من الماك

```bash
cd ~/Desktop/aidab
# عدّلي index.html ثم:
cp index.html public/index.html
git add index.html public/index.html
git commit -m "update site"
git push
```

## رفع يدوي (لو Git ما اشتغل)

ارفعي فقط: **Desktop/KINE-ONLY.zip** (ملف zip واحد)
